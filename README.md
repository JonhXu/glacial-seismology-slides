# 冰川地震学课程课件（Glacial Seismology Course Slides）

一份面向研究生与高年级本科生的 **50 页中文课程讲义**（PPTX），系统介绍冰川地震学（Glacial Seismology / Cryoseismology）这一冰冻圈科学与地震学交叉的快速发展领域。

## 内容结构

| 部分 | 页码 | 内容 |
|---|---|---|
| 封面与导学 | 1–3 | 课程封面、学习路线、总目录 |
| 第 1 讲 学科概览 | 4–9 | 学科演进、定义与简史、概念辨析、冰震五大族系、频带与尺度 |
| 第 2 讲 核心动力学过程 | 10–24 | 表层破裂与瑞利波判据、热致冰震、威兰斯冰川粘滑、速率–状态摩擦、谐频颤动、冰山崩解与 CSF 单力模型、冰川水力颤动（GHT）、幂律标度、水力压裂、冰架耦合、接地带（思韦茨冰川） |
| 第 3 讲 介质物理与波场 | 25–31 | 粒雪层结构、Q 值衰减（WIFF 机制）、横波分裂（SWS）、克雷里波、Press–Ewing 导波 |
| 第 4 讲 观测技术 | 32–38 | 极地台网、分布式光纤声学传感（DAS）、背景噪声干涉与 dv/v 监测、波束形成与 AI 检测 |
| 第 5 讲 灾害链监测 | 39–43 | 单力反演、青藏高原冰崩案例、查莫利 vs 布拉滕对比、冰湖溃决洪水（GLOF）双脉冲信号 |
| 第 6 讲 行星冰川地震学 | 44–47 | 冰卫星震相命名、土卫二/木卫二/土卫六/木卫三对比、蜻蜓号与 ShortSCOPE 展望 |
| 附录与收尾 | 48–50 | 核心术语中英对照表、总结与展望、思考题 |

## 特色

- **六讲 + 附录**的课堂结构，覆盖震源机制 → 介质波场 → 观测技术 → 灾害应用 → 行星前沿的完整知识链；
- 示意图、对比表格与数据图表穿插排版（粒雪层 Qp 柱状图、谐频谱峰折线图、GLOF 双脉冲曲线等）；
- 精选 16 组核心术语中英对照速查表，便于学生复习；
- 每页带章节导航条与页码，适合课堂讲授节奏。
